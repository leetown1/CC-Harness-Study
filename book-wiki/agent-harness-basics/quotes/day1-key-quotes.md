# 值得记住的原话

## Anthropic "Building Effective Agents"

> "Most successful implementations use simple, composable patterns rather than complex frameworks."
> （大多数成功的实现用的是简单、可组合的模式，而非复杂框架。）
>
> 来源：Anthropic 博客，2024 年 12 月

> "Workflows: systems where LLMs and tools are orchestrated through predefined code paths."
> "Agents: systems where LLMs dynamically direct their own processes and tool usage."
> （工作流：LLM 和工具按预定义路径编排的系统。Agent：LLM 动态控制自身流程和工具使用的系统。）

## 学习计划

> "Agent = Model + Harness"
> "Harness = Loop + Tools + Context + Guardrails"
> （核心公式，Agent 的一切工程挑战都归结为 Harness 的设计。）
